# AkiSync Go changelog

## 0.7.0 Git baseline

This entry summarizes the features already present when Git tracking began. The first commit captures them as a single snapshot.

- Named the Android app **AkiSync Go**. Existing installations use the same Android application ID.
- Store records in a local SQLite folder with a recovery copy and an optional app passphrase. Support importing patient lists and migrating older encrypted records.
- Manage patient profiles, treatment history, notes, alerts, tasks, and expected responses. Use Daily Laboratory Check to process lab returns and surface patients for booking.
- Book and reschedule visits with duration presets, availability and break rules, conflict checks, and suggested times. Review outstanding appointment outcomes from Today or Calendar.
- Show Android calendar events in the schedule and optionally publish visits to a dedicated Google Calendar. Support availability and daily lab reminders.
- Preview mobile workflows in a Galaxy S24 Ultra frame, with Turkish and English interface options.
